# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

Volume Monitor is a local audio monitoring tool that communicates only with
BitFocus Companion over your local network. It does not expose any network
services, accept external connections, or transmit data over the internet.

If you discover a security vulnerability, please open an issue on GitHub
with the details rather than posting publicly, to give maintainers time
to address it.

**Do not** report security issues via the public issue tracker if they
could compromise user systems. Instead, email the maintainers directly
or open a [GitHub Security Advisory](https://github.com/Tech127x/volume-monitor/security/advisories).

We will acknowledge receipt within 48 hours and provide an estimated
timeline for a fix.
